## 📌 Project Overview
This repository contains the end-to-end implementation of **Task 2: Exploratory Data Analysis (EDA)** completed as part of the **CodeAlpha Data Analytics Virtual Internship**.

## 🎯 Task Criteria Addressed
- [x] **Ask Meaningful Questions**: Formulated 5 domain-critical questions prior to coding.
- [x] **Explore Data Structure**: Examined 891 rows, 12 features, data types, and null percentages.
- [x] **Trends & Outliers**: Used IQR method to identify 13.0% outliers in Ticket Fare and plotted KDE curves.
- [x] **Hypothesis Testing**: Formulated H0 and H1 hypotheses, verified via Chi-Square and Welch's T-Test ($p < 0.05$).
- [x] **Data Quality Issues**: Imputed missing Age values via conditional group medians and normalized Fare skewness via log transformation ($4.79 \rightarrow 0.39$).

## 📊 Key Findings
1. **Gender Advantage**: Females had a 74.20% survival rate vs. 18.89% for males ($p = 1.20 \times 10^{-58}$).
2. **Socio-Economic Class Disparity**: 1st Class passengers survived at 62.96% compared to only 24.24% in 3rd Class.
3. **Ticket Fare Impact**: Survivors paid an average fare of £48.40 vs. £22.12 for deceased passengers ($p = 2.70 \times 10^{-11}$).
